# Fase 01 — shell Electron/React

## F01-T01 — runtime desktop

Crear Electron Main, preload aislado, menú nativo y carga de renderer local. No habilitar Node en el renderer.

## F01-T02 — workbench demo

Construir una única superficie React con explorador, tabs, resumen, actividad, proyecto demo, chat local y statusbar. La navegación actualiza el contexto visible.

## F01-T03 — evidencia

Ejecutar Playwright contra Electron real; comprobar arranque, cambio de tema, navegación y envío de un mensaje; guardar capturas oscuras y claras.

## F01-T04 — gate

Registrar salidas, limitaciones y checklist manual. No iniciar persistencia LangGraph, OMP real ni brownfield.
