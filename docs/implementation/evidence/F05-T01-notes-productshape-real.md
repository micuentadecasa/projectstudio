## Resumen 1. **[Hecho] Propósito:** DrumCoach convierte audio, MIDI, eventos o imágenes de partitura aportados por el aprendiz en material de práctica local: partes instrumentales, partituras, notación y reproducción sincronizada. Evidencia: `docs/product/architecture.md:5-9,34-40`; corroborado por `src/drumcoach_app/main.py:870-1011` y `src/drumcoach_app/import_runner.py:426-594`. 2. **[Hecho] Actores:** aprendiz, operador local, motor MuScriptor y runtime OMR opcional. Evidencia: `docs/product/model/actors/act-learner.md`, `act-local-operator.md`, `act-muscriptor.md`, `act-omr-runtime.md`. 3. **[Hecho] Casos de uso:** importar fuentes, importar imágenes de partitura, ejecutar el worker local, explorar la biblioteca, practicar una revisión y pedir coaching contextual. Evidencia: `docs/product/model/use-cases/`. 4. **[Hecho] Bounded contexts:** Practice Material, Instrument-Specific Ingestion, Interactive Notation Player y Contextual Practice Coaching. Evidencia: `docs/product/model/domain/bounded-contexts/`; corroborado por `repository.py`, `import_runner.py`, `player.py` y `teacher/analyse.py`. 5. **[Hecho] Reglas centrales:** Practice Score JSON es canónico; MusicXML, MIDI, diagnóstico y engraving son derivados; los jobs son locales y específicos por instrumento; el coaching analiza determinísticamente y exige confirmación antes de reproducir. Evidencia: `docs/product/model/business-rules/`; corroborado por `practice_score.py:99-250`, `repository.py:213-256` y `assistant/tools.py:1423-1508`. ## Decisiones observadas - **[Hecho] Local-first:** una aplicación FastAPI, un worker local, SQLite y archivos configurables; no hay catálogo alojado, autenticación ni cola distribuida. Evidencia: `docs/product/model/business-rules/br-local-first.md`, `con-local-sqlite.md`, `src/drumcoach_app/repository.py:178-327`. - **[Hecho] Ingesta por instrumento:** los perfiles por defecto son batería, piano acústico y guitarra acústica; una importación puede crear jobs hijos por parte. Evidencia: `src/drumcoach_app/main.py:99-112`, `src/drumcoach_spike/transcription_adapter.py:18-36`, `src/drumcoach_app/repository.py:225-256`. - **[Hecho] Persistencia reproducible:** cada job exitoso publica eventos raw, eventos normalizados, score canónico, MusicXML, resumen, provenance, diagnósticos, playback y `note-trace.json`, y después registra Song, Instrument Part y revisión. Evidencia: `src/drumcoach_app/import_runner.py:461-529,553-594`. - **[Hecho] Player único:** las vistas del reproductor y el asistente convergen en `PlayerController`; el estado de selección, tempo, loop, fuente y transporte se conserva como una única sesión. Evidencia: `src/drumcoach_app/player.py:316-410,412-564`; endpoints `/assistant/player-session` y `/assistant/player-command` en `src/drumcoach_app/main.py:669-779`. - **[Hecho] Coaching con límite humano:** el análisis usa score y selección autorizados; el modelo recibe payloads acotados y no calcula hechos musicales. La reproducción se propone, queda pendiente y sólo se ejecuta tras confirmar canción y rango. Evidencia: `src/drumcoach_app/teacher/analyse.py:39-95`, `src/drumcoach_app/assistant/tools.py:911-1011,1423-1508`. - **Vista confirmada:** ```mermaid flowchart LR L["Aprendiz"] --> V["Viewer y superficie de práctica local"] O["Operador local"] --> API["FastAPI + worker local"] V --> API L --> SRC["Audio / eventos / URL / imagen"] SRC --> API API --> ING["Ingesta específica por instrumento"] MS["MuScriptor"] --> ING OMR["OMR opcional"] --> ING ING --> MAT["Practice Material"] MAT --> DB[("SQLite local")] MAT --> ART[("Archivos y artefactos locales")] MAT --> PLAYER["Interactive Notation Player"] PLAYER --> L MAT --> COACH["Contextual Practice Coaching"] L --> COACH COACH -->|"guía y acción pendiente"| L L -->|"confirmación"| COACH COACH -->|"acción validada"| PLAYER ``` ## Riesgos - **[Incógnita de producto]** Coaching contextual, voz, benchmarks, multiinstrumento y engraving aparecen como capacidades experimentales u opt-in, no como compromisos de producto inequívocos. Evidencia: `docs/product/architecture.md:7-10,57-67`. - **[Riesgo de trazabilidad]** La documentación mantiene la limitación histórica de “no soporte no-4/4” en `docs/product/architecture.md:101-108`, mientras el código actual acepta `time_signature` y calcula compases con `ticks_per_bar`: `src/drumcoach_spike/practice_score.py:99-147`. Debe decidirse si es una limitación vigente o una nota histórica. - **[Riesgo operativo]** OMR, MuScriptor, FFmpeg, fuentes de audio y otros runtimes dependen de instalación local; la ausencia debe producir fallos durables visibles, no bloqueos silenciosos. Evidencia: `docs/product/model/requirements/constraints/`, `src/drumcoach_app/main.py:920-968`. - **[Riesgo documental]** `graphify-out/GRAPH_REPORT.md:13-16` fue generado sobre el commit `e7a7fe89`; el repositorio actual está en otro commit (`a5cb123b...`). El grafo sirve como navegación histórica, no como evidencia actual hasta regenerarlo. - **[Frontera especial]** `/midi-import` explora MIDI directamente y no crea una revisión canónica; está explícitamente separado del flujo de Practice Score.
