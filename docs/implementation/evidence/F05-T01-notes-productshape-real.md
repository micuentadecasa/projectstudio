Propósito y frontera del producto **DrumCoach es una herramienta local-first de práctica musical personal.** El aprendiz aporta audio/video permitido, eventos/MIDI o una imagen de partitura; el sistema produce material específico por instrumento, lo guarda localmente, muestra notación y permite practicarla con playback sincronizado. La frontera explícita es: - Aplicación FastAPI local. - SQLite local para identidad y ciclo de vida. - Archivos locales para scores, fuentes retenidas y artefactos. - Superficie web local para biblioteca, notación, reproducción y coaching. - Sin catálogo público alojado, autenticación, API pública de transcripción, cola distribuida ni contrato de soporte de producción. Evidencia documental: `docs/product/architecture.md:5-9,44-67,101-108`. Corroboración: - Rutas FastAPI de salud, importación, biblioteca, scores, artifacts y player: `src/drumcoach_app/main.py:317-323,870-1011,1231-1470`. - Esquema SQLite y entidades locales: `src/drumcoach_app/repository.py:180-257`. - Launcher que inicia servidor y worker en la misma máquina: `scripts/run-local-app.sh:14-28,81-95`. ## 2. Bounded contexts ### 4.1 Instrument-Specific Ingestion **Responsabilidad:** adquirir o leer fuentes, ejecutar el adaptador de transcripción u OMR y producir revisiones de score específicas por instrumento. - Lenguaje: Import Bundle, Import Job, source kind, requested instrument, profile, provenance, OMR. - Límites: jobs locales en SQLite; MuScriptor aislado por adapter; OMR y MuseScore opcionales. - Evidencia: `docs/product/model/domain/bounded-contexts/bc-transcription.md:12-22`; `src/drumcoach_app/import_runner.py:192-285,426-590`. ### 4.2 Practice Material **Responsabilidad:** representar Song, fuente, partes instrumentales, revisiones y artefactos derivados. - El `Practice Score JSON` es la fuente canónica. - MusicXML, MIDI, summaries, diagnósticos y engraving son derivados. - Evidencia: `docs/product/model/domain/bounded-contexts/bc-practice-material.md:12-22`; `docs/product/model/business-rules/br-score-json-canonical.md:14-24`. ### 4.3 Interactive Notation Player **Responsabilidad:** presentar notación y reproducción sincronizadas sobre score time. - No modifica el score canónico. - Usa `PlayerController`, payload generado, audio original opcional y proyecciones del navegador. - Evidencia: `docs/product/model/domain/bounded-contexts/bc-practice-playback.md:12-22`; `src/drumcoach_app/generated_playback.py:47-103`; `src/drumcoach_app/player.py:316-410`. ### 4.4 Contextual Practice Coaching **Responsabilidad:** analizar material seleccionado y devolver orientación pedagógica acotada. - El análisis musical es determinista. - El LLM sólo reexpresa. - Las acciones de reproducción esperan confirmación. - Evidencia: `docs/product/model/domain/bounded-contexts/bc-practice-coaching.md:12-22`; `src/drumcoach_app/teacher/analyse.py:39-95`. ## 5. Reglas e invariantes 1. **Score JSON canónico.** MusicXML, MIDI y diagnósticos no pueden convertirse silenciosamente en otra fuente de verdad. `docs/product/model/business-rules/br-score-json-canonical.md:14-24`; `src/drumcoach_app/import_runner.py:450-529`. 2. **Derivación reproducible.** Notación y playback se regeneran desde score y provenance retenidos. `docs/product/model/business-rules/br-derived-artifacts.md:14-24`; `src/drumcoach_app/main.py:1335-1362,1450-1469`. 3. **Ingesta específica por instrumento.** Cada job apunta a una familia/perfil; un bundle puede crear varios jobs hijos bajo un Song. `docs/product/model/business-rules/br-instrument-specific-jobs.md:14-24`; `src/drumcoach_spike/transcription_adapter.py:23-36,159-198`. 4. **Historial de revisiones.** Una nueva revisión no debe borrar silenciosamente la anterior; la parte mantiene una revisión activa direccionable. `docs/product/model/requirements/functional/fr-persist-score.md:17-21`; `src/drumcoach_app/repository.py:696-741`. 5. **Fallos observables.** Un job fallido conserva mensaje de error y no reclama éxito; cancelación evita publicar un resultado. `docs/product/model/behaviours/sb-import-score.md:7-24`; `src/drumcoach_app/repository.py:906-972`; `tests/test_import_runner.py:176-200`. 6. **Coaching grounded y confirm-first.** El assistant no calcula ticks ni ejecuta directamente acciones de player. `docs/product/model/business-rules/br-human-review-teacher.md:14-24`; `src/drumcoach_app/teacher/__init__.py:11-19`. 7. **Excepción no canónica.** El explorador directo `/midi-import` transcribe para explorar MIDI y no crea una revisión de Practice Score; el camino canónico sigue siendo el import runner. `src/drumcoach_app/main.py:505-536`; `src/drumcoach_spike/transcription_adapter.py:200-204`. ## 6. Restricciones - **Local-first:** una máquina, archivos locales, SQLite y runtimes locales; no hay broker ni scheduler distribuido. `docs/product/model/business-rules/br-local-first.md:13-24`; `docs/product/model/requirements/constraints/con-local-sqlite.md:13-20`. - **Baseline documentada:** macOS, `uv`, FFmpeg y Python `>=3.11`; Docker no es necesario para el flujo v1 documentado. `docs/product/model/requirements/constraints/con-macos-local-runtime.md:13-20`; `pyproject.toml:1-12`. - **Fuentes soportadas:** `raw_events`, `local_audio`, `youtube_url`, `score_image`. `src/drumcoach_app/main.py:110-113`; `src/drumcoach_app/repository.py:225-255`. - **Imagen de partitura:** sólo PNG, JPEG y WebP; límite de 25 MB; PDF rechazado; requiere OMR local opcional. `src/drumcoach_app/main.py:920-968`; `src/drumcoach_spike/omr.py:60-103`; `tests/test_score_image_import.py:66-118`. - **Audio subido:** tipos de audio concretos y límite de 100 MB en la ruta HTTP; la transcripción impone máximo de diez minutos antes de inferencia. `src/drumcoach_app/main.py:879-918`; `tests/test_import_runner.py:203-232`. - **OMR opcional:** su ausencia no impide arrancar la aplicación; el job de imagen falla de forma durable con guía de configuración. `docs/product/model/requirements/constraints/con-optional-omr.md:13-20`; `docs/product/model/behaviours/sb-score-image-omr-failure.md:7-26`. - **Voz opcional:** STT/TTS son adaptadores locales alrededor de `/assistant/turn`; no llaman directamente al player ni al modelo LFM. `docs/product/model/requirements/constraints/con-optional-voice.md:13-20`. - **Limitaciones de producto declaradas:** sin editor completo de correcciones, stem muting, mapas de tempo generales ni garantías de playback de producción; algunas rutas recientes de teacher, piano, guitarra y engraving son opt-in o experimentales. `docs/product/architecture.md:101-108`. ## 7.
